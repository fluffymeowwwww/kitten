# 同创汇猫咪故事馆 · 玩法设计文档

> 日期：2026-09-10
> 状态：玩法已对齐，待视觉稿确认
> 全局约束：所有产物遵循《小红书小工具开发规范》（完全离线 / JS 外置 / 无内联事件 / 包内仅 html·css·js·图片·woff2·json）

## 一、产品一句话

伸手摸一只猫 → 读 TA 的故事 → 留句话 → 生成一张带「你名片」的共鸣卡，保存发笔记。

## 二、核心闭环

```
封面「去摸摸小猫」
   ↓ （首次）入馆登记：昵称 + 头像（复古预设 / 相册选图）+ 一句简介
   ↓
摸猫：伸手动画 → 随机一只（洗牌不重复，15 只摸完一轮再重置）
   ↓ 三档性格反应（统一剪影/插画动画，无论哪种反应故事都完整可读）
   ↓
故事页：照片或剪影 + 猫名 + 花色·性别标签 +「等家 / 有家了」状态
        故事文案中其他猫名为热词，点击串门；卡片角落有家族小标签
   ↓
留言：4-6 句预设短句可选，也可自己打字
   ↓
共鸣卡（Canvas 2D 生成图片，保存到相册发笔记）
   ↓
「再摸一只」循环
```

## 三、页面清单

| 页面 | 内容 |
|---|---|
| 封面（保持原样，仅改入口文案） | 倒计时 + 街角群猫插画 + 标题全部不变；主按钮文案为「摸一摸小猫」，点击进入摸猫页 |
| 入馆登记 | 昵称输入、头像选择（6-8 个复古预设 + 相册选图）、一句简介；可跳过/以后再改 |
| 摸猫页 | 核心主视觉 + 伸手动作；摸中后按性格播三档反应 |
| 故事页 | 猫照片（无照片用剪影 +「TA的照片还在路上」）、名字标签、故事正文、热词串门、家族标签、等家状态 |
| 留言 + 共鸣卡 | 预设短句/自写留言；卡片实时预览；保存图片 |
| 图鉴（猫墙） | 15 只猫全部可见、平权排列；摸过的猫多一个爪印标记；点任一只直接进故事 |

## 四、关键机制

### 1. 摸猫随机
- 15 只等概率，**无稀有度**；洗牌算法保证一轮内不重复，摸完重置
- 两个入口：封面/首页「去摸摸小猫」= 随机；图鉴 = 主动挑一只

### 2. 性格三档反应（轻量，无操作成本）
| 性格 | 反应 | 代表猫 |
|---|---|---|
| 亲人 | 一摸就贴手心、翻肚皮 | 铁白、绅士、彩虹、瓜瓜、猪仔、三眼妹、三姐妹 |
| 中等需培养 | 先退半步，闻闻手指，勉强让摸 | 小银、milo、灵珠、队娃 |
| 不亲人 | 手伸过去嗖地躲掉，只留尾巴尖 + 旁白 | 大华、小梅、点白 |

- 反应动画用统一风格插画/剪影，成本低、与复古海报风兼容
- **任何反应后故事都完整展示**，不存在「白摸一次」
- 不亲人猫的旁白方向：「TA 还没准备好。不是每只猫都要被摸到，你愿意看见 TA，就很好了」

### 3. 猫际关系线
- 故事正文中出现的其他猫名为可点热词，点击跳到那只猫的故事
- 图鉴卡片角落放家族小标签（瓜瓜家族/小队家族/粽妈家族/小梅家族/大脸家族/大黄家族）
- 不画关系网连线（15 只会乱）

### 4. 共鸣卡内容
- 猫照片 / 剪影
- 猫名 + 花色·性别标签
- 故事金句（每只猫最打动人的一句）
- 用户留言（预设短句或自写）
- 拆迁倒计时（按 2026-11-30 动态计算）
- 故事馆署名「同创汇猫咪故事馆 · VOL.01 秋日来信」
- 摸猫人名片：头像 + 昵称 + 简介
- **不放编号**（离线本地计数会被误读为全站人数，涉虚假数据）

### 5. 图鉴
- 15 只全部可见、同等大小，不锁、不排名
- 摸过的猫加爪印标记
- 无照片猫统一剪影 +「TA的照片还在路上」

## 五、内容红线

- **地点模糊化**：文案中「地铁口 / 果园 / 乐水浆」等具体位置改写成不暴露地点的说法（保护流浪猫安全）
- 无票数、无全站人数、无编号、无假故事数
- 插画为艺术形象，非纪实还原；有照片的猫必须用真实照片素材
- 数据预留 `adopted` 字段：将来某只被领养，重新打包时翻转为「TA 有家了」温暖结局
- 倒计时 deadline 2026-11-30，动态计算，不写死天数

## 六、猫池（15 只，打包固化为 cats.json）

瓜瓜、小银、猪仔、三眼妹（无照）、大华（无照）、小小猫/小猫/中猫三姐妹（无照）、铁白、milo、小梅、点白、小队&队娃家庭卡（无照）、彩虹、绅士。

## 七、技术形态

- 纯静态离线：`index.html`（封面）+ 单页内页（视图切换）+ 外置 JS，无内联脚本/事件
- `cats.json` 固化数据；照片、剪影插画、预设头像全部打包进 `assets/`
- localStorage 存登记信息与摸过记录，key 加项目前缀
- 共鸣卡用 Canvas 2D 绘制导出图片
- 竖屏 375~430px 适配，触控目标 ≥44px
- 视觉工作流沿用封面：AI 生图 → 切片 webp → HTML 排文字；纸纹复用 `assets/paper-grain.png`

## 八、视觉资产清单（生图切图）

1. 摸猫主视觉（伸手 + 纸箱/猫群，暖光复古 gouache 风，竖版）
2. 性格反应三档分镜（贴手心 / 闻手指 / 尾巴尖逃跑，一张三格切片）
3. 预设头像集（6-8 个复古风小头像，一张 sprite 切片）
4. 共鸣卡装饰（邮戳/邮票/期刊元素小图）
5. 无照片猫占位用纯色剪影（SVG，风格统一）
