# 同创汇猫咪故事馆（版本2）

同创汇主题的第二个产品方向：与版本1「猫咪守护计划」（抽卡/守护证书玩法，另一个仓库）相互独立，本仓库走「故事馆」玩法——遇见猫、读真实故事、留下共鸣、人气榜传播。

当前进度：封面视觉试样（v4 复古插画海报方向）。

## 视觉方向

复古动画电影海报：深松绿、陶土橘、奶油纸与金色暖光。主视觉用 AI 生图获得完整的街角群猫插画，再切成场景上部、群猫中部、前景下部三个连续素材。文字、倒计时和按钮用真实 HTML 排版，保留清晰度、可访问性与后续交互能力。

与 v2 的手账拼贴、v3 的水彩装饰相比，v4 将画面重心放在完整的环境插画、角色神态和光影上。页面没有用 CSS 重绘猫或街景。

## 查看

- `index.html`：封面页面，可直接打开；也可在仓库根运行 `python3 -m http.server 4174 --bind 127.0.0.1` 后访问 `http://127.0.0.1:4174/`。
- `cover-preview.png`：390 CSS 像素宽、2 倍清晰度的实际浏览器截图。
- 主按钮暂为占位（`#`），故事馆内页（群像墙/故事盲盒/共鸣卡/人气榜）待开发，玩法与文案见 `docs/故事馆文案草稿.md`。

## 素材

- `source/cover-art.png`：原始生图，1254 × 1254。
- `prompts/cover-art.txt`：实际完整提示词。
- `source/generation.json`：请求参数、返回参数和 usage。
- `assets/scene-top.webp`：规范化 1024 像素源图的 y=0–320。
- `assets/scene-cats.webp`：y=320–800。
- `assets/scene-ground.webp`：y=800–1024。
- `assets/paper-grain.png`：固定随机种子的轻纸纹。
- `scripts/slice_art.py`：用 Pillow 从原图重建切片；不再次调用生图 API。

运行 `python3 v4-illustrated/scripts/slice_art.py` 可重建切图。

本次以文生图方式调用 OpenTK，返回模型 `gpt-image-2-codex`、quality `auto`、1254 × 1254；usage 为 input 485 / output 2058 / total 2543 tokens。

## 内容边界

插画中的街景、猫咪是表现主题的艺术形象，不是同创汇现场或具体猫咪的纪实还原。截止日期沿用 v1 的 `2026-11-30`（北京时间日末），尚待业务确认；页面按实际时间计算，不将“82 天”写死。不引入假故事数、投票数或未经确认的领养进展。

页面静态资源自包含、无外部依赖与网络 API；JS 外置。整个封面目录可独立分发。
